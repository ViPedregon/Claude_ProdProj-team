# claude-nexus-hyper-agent-team

This repository now contains the requested starter scaffold for a Claude hyper-agent team.

## Included structure

- 31 placeholder agent definitions in `/agents`
- Runtime hooks in `/hooks`
- Contract test entry point in `/tests/agents/run_contract_tests.py`
- Team documentation in `/docs/team`
- Per-agent memory, signal bus, shadow mind, and trust ledger scaffolding in `/agent-memory`
- Root hook configuration files in `settings.json` and `settings.local.json`
